Keep in mind that everything is a trade-off.

----
Trade-off = gaining one thing while potentially giving up another

Imagine you have ₹100.

You can spend it on:

🍕 Food
🎮 A game

If you spend all ₹100 on food, you gain more food but give up the game.

That's a trade-off.

In system design

We constantly make decisions where there isn't a perfect solution.

For example:

Caching

Database → Cache

You gain:

✅ Faster responses
✅ Less database load

But you may give up:

❌ Immediate freshness

Because the cache might contain old data.

That's a trade-off.
-----

So when the Primer says:

"Keep in mind that everything is a trade-off."

It means:

Don't ask "What's the best technology?" Ask "What's best for these requirements, and what are we sacrificing?"

That's a system designer's mindset.

3 words: Every choice sacrifices something.
